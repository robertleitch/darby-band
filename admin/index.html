1 · Unlock

Enter the admin password.

Enter it once, on your computer. It's saved scrambled with the admin password, so after that your phone and other devices only need the admin password. Leave blank otherwise. How to get one

Send to Claude

Paste a link (a competition page, parking info, a map) and/or type anything: a director email, new times, a schedule change. Tap Save, then open Claude on your phone or computer and say process the inbox. Claude reads it, works up the site update, and shows you the changes before anything goes live.

2 · Performance videos

Paste a Vimeo or Facebook link for a show. Leave it blank for no video. Vimeo links play right on the site; Facebook links open Facebook. Videos only appear behind the password.

3 · Splash photos

One of these shows at random when someone opens the site. Tap a photo to set the spot that stays in view on phones. Changes go live in about 1–2 minutes.

4 · Visitor stats

Only you can see these. They open in GoatCounter and need your GoatCounter login.

Open stats ↗
Turn this on for each phone and computer you use, so your own testing doesn't inflate the numbers.

Getting a GitHub key (one time)

1. On github.com, click your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Name it "Darby admin", set an expiration, and under Repository access choose Only select repositories → darby-band.
3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
4. Generate, copy it, and paste it above. Don't share it with anyone; it can change the site.
